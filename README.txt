# Hani AI Web App

## Local setup

1. Install dependencies:
   python -m pip install -r requirements.txt

2. Set your Groq API key in Windows CMD:
   set GROQ_API_KEY=YOUR_NEW_GROQ_API_KEY

3. Run:
   python app.py

4. Open:
   http://127.0.0.1:5000

Never put the Groq API key inside index.html or JavaScript.
